# Nightjar Coffee Roasters — Flagship Digital Experience

An award-winning, editorial single-page digital experience built for **Nightjar Coffee Roasters** (Warehouse G62, Alserkal Avenue, Dubai).

## ☕ Key Features

1. **Live Dubai Business Hours**: Calculates operating status (09:00 AM – 10:00 PM GST) in real-time with dynamic countdowns.
2. **Interactive Nitro Taproom**: Explore single-origin draft cold brews with sensory tasting matrices and draft specifications.
3. **Micro-Roastery Blend Matrix**: Interactive coffee beans selector (GONZO, S.O.B, CANDYMAN) with acidity/sweetness/body scales and 225g/1kg pricing toggles.
4. **Complete Deliveroo & In-House Menu**: Real AED pricing for kitchen specials (Rendang Scramble, Dibba Bay Buttie, Alserkal Smash) with search and category filtering.
5. **Real Verified Reviews**: 4.7★ community testimonials sourced directly from Google Maps and Deliveroo.
6. **Warehouse G62 Editorial Gallery**: Categorized photo grid with keyboard-controlled lightbox modal.
7. **Direct Action Triggers**: One-tap phone calling, direct WhatsApp messaging, Deliveroo instant ordering, and interactive table/event reservation forms.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom glass-panel utilities and noise overlays
- **Icons**: Lucide React
- **Typography**: Syne, Plus Jakarta Sans, and Space Mono (Google Fonts)
- **Metadata**: JSON-LD `CafeOrCoffeeShop` schema, Open Graph tags, and WCAG AA accessible contrast.

## 🚀 Running the App

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
